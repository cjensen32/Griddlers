## The critique that preceded it

Delivered in conversation rather than written into a file, because the learner owns `src/` and naming a gap is the help being asked for. Recorded here as the list, without the fixes:

- `Cell` — `asciiStr()` names storage and encoding rather than the concept, and Chapter 3's Unicode migration makes the name actively wrong. Nothing pins the payload to a single character, which is the invariant that migration breaks. `CellTest` is `public` while `GriddlerTest` is package-private, in the same package.
- `Griddler` — `new Griddler(null)` throws `NullPointerException` while every other invalid input throws `IllegalArgumentException`, and nothing tests it. `getCells()` returns an unmodifiable outer list wrapping mutable rows, so `snapshot.add(...)` throws and `snapshot.get(0).add(...)` silently succeeds. `setCell` validates the cell before the coordinates, and which check wins is a contract no test holds.
- `GriddlerTest` — no test proves the constructor copies its argument, only that `getCells` copies its result. Deleting `List.copyOf` leaves the suite green. `constructorRejectsEmptyCellRow` passes for the wrong reason: the square check throws before the loop reaches the empty row, making it a duplicate of the ragged test. `constructorRejectsRaggedRows` stacks three bare `assertThrows`, so the first failure masks the other two. Rows 2 and 3 of the fixture are identical, which is weaker than the fixture's own comment claims.
- Staged work — the engine's render method is an overload of `Object.toString()` rather than an override; the 4x4 fixture lives in the I/O layer inside a static initialiser that catches `Exception`; the write uses `FileWriter(String)` into `~/Downloads` with the `IOException` swallowed; the production method carries a `test` prefix; and the composition root prints while the class named for printing returns.
