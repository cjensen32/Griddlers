# Refit Lesson 2.3 to the three packages, and rebalance the lesson format

Dated 2026-09-11. Approved by the learner across seven review rounds before any file changed.

## Context

2.3 was written as "the two packages" — an engine at `com.connorjensen.griddlers` with `tools` beneath it. The learner built a better shape: `Main` alone at the root, with `engine`, `model`, and `tools` as three peers, and rewrote `checkstyle.xml` and `import-control.xml` against it.

The lesson no longer described the repository. The larger problem was that the chapter had drifted into configuration with almost no code behind it — rules nothing exercised, five probe fixtures existing only because real code gave the rules nothing to bite on, and a thirteen-row verdict matrix to be filled once and never reopened.

The learner named the cause: the lessons were written so they could be *completed* without producing anything worthwhile. Acceptance meant the rules laid out in the lesson had been followed, not that good code got written. This refit shifts that paradigm, and records the shift in `PROJECT.md` and `COURSE_STANDARDS.md` so it governs later lessons rather than only this one.

## What the config changes were, and why

The agent edited `checkstyle.xml` and `import-control.xml` at the learner's explicit request, who had spent long enough on them and wanted the corrections made rather than assigned. They are the learner's to review.

- **`checkstyle.xml`:** removed `MatchXpath //LITERAL_NEW/DOT`. Nothing in the tree writes a fully-qualified instantiation, and the query also matches legitimate nested-type instantiation. Kept `RegexpSinglelineJava \bSystem\b` and its `SuppressionSingleFilter`, which start meaning something once `Main` prints and `TerminalGriddler` renders.
- **`import-control.xml`:** rewritten as a layered allowlist. The previous root declared `<disallow pkg="java">` before `<allow pkg="java\.util">`, so the allow was unreachable and the engine could not import a collection at all. `strategyOnMismatch` on `<import-control>` already defaults to `disallowed`, so the blanket disallows were decoration; every line is now a permission.
- The root allows `tools`, because it holds `Main` and wiring the program together is its job. `engine` and `model` carry `strategyOnMismatch="disallowed"` so they cannot inherit that reach.
- **Found by probing, not by reading:** the root's `<file name=".*Test">` block, declared before the subpackages, claimed every matching file in the tree and shortcut the subpackage rules — an engine test was refused `model.Griddler`. Declaration order decides node resolution. The subpackages are now declared first and each carries its own `<file>` block, with the root's last.

Verified in a scratch copy outside the repository: six rejections on a boundary-violating engine class, zero on a legitimate subpackage test, and `mvn -B checkstyle:check` green on the real tree.
